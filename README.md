## Running a solution

Compile a C or C++ file on its own, then provide the problem input on standard input. For example:

```sh
gcc -std=c11 228A/228A.c -o /tmp/solution
/tmp/solution
```

For C++ use `g++ -std=c++11` in place of `gcc -std=c11`. Run the Python solution with `python3 112A/112A.py`.
